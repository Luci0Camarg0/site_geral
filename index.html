Modo editor

Para adicionar, mover e apagar itens, o site salva direto no seu repositório do GitHub. Ele precisa de uma chave de acesso (token), que fica guardada só neste navegador.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories e marque site_geral
  3. Em Permissions, ache Contents e mude para Read and write
  4. Clique em Generate token, copie e cole aqui

Armazenamento

Para guardar os arquivos no Cloudflare (10 GB grátis), cole aqui o endereço do seu Worker, que termina em workers.dev. O passo a passo para criar está no README do repositório. Os arquivos que já estão no GitHub continuam funcionando.
